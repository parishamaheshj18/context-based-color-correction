Color correction that understands the scene

Cameras guess the color of light from pixel statistics, and fail when a scene is dominated by one color or lit by tungsten, LEDs, or shade. This project lets a vision-language model read the scene: which surfaces are white paper, gray concrete, foliage, skin, and which of them can be trusted. Physics then turns those surfaces into a color correction, as if they were patches on a color chart.

    Where the AI is used

    Two stages use learned models. Both make decisions: what is in the scene, where it is, and whether to trust it. Every output pixel is produced by one global 3×3 color matrix fitted with physics, so no image content is ever generated.

    1. PhysicsDecode RAWLinear sensor RGB, no camera processing
    2. AI · ClaudeRead the sceneIndoor or outdoor, light sources, which materials are present and whether each is trustworthy
    3. AI · Claude + SAMFind the materialsClaude boxes each trusted surface; Segment Anything turns the boxes into pixel masks
    4. PhysicsMeasure patchesReject clipped, specular, and shadowed pixels; robust color per region
    5. PhysicsFit the lightDaylight / tungsten spectra fitted to reflectance priors, outliers rejected
    6. PhysicsCorrect & renderSpectral 3×3 color matrix, optional mood-preserving adaptation

    In each gallery card, the AI reasoning tab shows the model's exact answer, and Regions shows the pixels it chose.

    Measured accuracy

    Four lab photos contain a ColorChecker. The chart is blacked out before any stage runs (the AI never sees it) and used only afterwards to measure the true light color. Lower is better; under 1° is hard to see, over 3° is a visible cast.
